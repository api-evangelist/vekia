# Vekia

> Vekia is a French supply-chain software vendor (Vekia SAS, 143 rue d'Athènes,
> 59800 Lille), founded 2008 by Manuel Davy, selling Vekia Engine — a
> probabilistic-AI demand forecasting and automated replenishment platform that
> pushes optimised purchase-order proposals back into a customer's ERP. Vekia
> publishes NO public API, NO developer portal, NO API reference and NO
> machine-readable contract (no OpenAPI, AsyncAPI, GraphQL SDL, JSON Schema or
> Postman collection). Integration with ERP/WMS/TMS systems is delivered by
> Vekia as a project, not through a self-serve developer surface.

## Developer surface — what does NOT exist

- No developer portal. developer.vekia.fr, docs.vekia.fr, api.vekia.fr, app.vekia.fr, portal.vekia.fr and status.vekia.fr do not resolve (NXDOMAIN).
- No API reference. https://www.vekia.fr/developers and https://www.vekia.fr/api return HTTP 404.
- No specification. /openapi.json, /swagger.json and /api-docs return the site's HTML 404 page; /openapi.yaml returns HTTP 403 from the edge. Nothing parses as OpenAPI or Swagger.
- No SDKs, no CLI, no packages in npm, PyPI, RubyGems, crates.io, NuGet, Maven Central, pkg.go.dev or Packagist. No GitHub organization (github.com/vekia → HTTP 404).
- No A2A agent card at /.well-known/agent-card.json or /.well-known/agent.json (both 404).
- No security.txt, no status page, no changelog, no sandbox, no webhooks, no AsyncAPI, no published rate limits and no published pricing.

## Machine-readable surfaces that DO exist on www.vekia.fr

These belong to the WordPress installation that serves the corporate site. They
are NOT the Vekia Engine product API.

- [OAuth 2.0 Authorization Server Metadata](https://www.vekia.fr/.well-known/oauth-authorization-server) (RFC 8414, HTTP 200) — authorization_code + refresh_token, PKCE S256, scope `mcp`
- [OAuth 2.0 Protected Resource Metadata](https://www.vekia.fr/.well-known/oauth-protected-resource) (RFC 9728, HTTP 200) — names an MCP endpoint at https://www.vekia.fr/wp-json/mcp/mcp-oauth-server
- MCP endpoint: https://www.vekia.fr/wp-json/mcp/mcp-oauth-server — OAuth-gated; unauthenticated `tools/list` returns HTTP 403 `wp_die` "You are not authorized to perform this action."
- WordPress REST API: https://www.vekia.fr/wp-json/wp/v2 (HTTP 200, route+argument schema). The namespace index at /wp-json/ is blocked (HTTP 403).
